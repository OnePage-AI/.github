# 문제 해결 기록

이 페이지는 서비스 운영 과정에서 사용자 흐름에 직접 영향을 준 문제와 해결 판단을 공개 가능한 범위에서 기록합니다.

## 모바일 결과 화면의 정보 밀도

**문제**  
데스크톱에서 자연스러운 원본/결과 배치와 여러 액션이 모바일에서는 한 화면에 몰려 결과를 읽기 어려웠습니다.

**판단**  
모바일에서는 결과 읽기를 우선하고, 필요한 기능만 명확하게 접근할 수 있도록 조작 요소를 정리하는 방향을 선택했습니다.

**결과**  
작업 화면에서 학습 결과와 주요 액션의 우선순위가 명확해지고, 원본 확인은 필요한 시점에 이동하는 방식으로 개선할 수 있었습니다.

## 요약 결과의 표 가독성

**문제**  
열이 많은 표가 모바일 폭에 맞춰 지나치게 압축되면서 한글이 글자 단위로 줄바꿈되어 읽기 어려웠습니다.

**판단**  
표의 의미 구조를 다른 카드 형태로 바꾸기보다, 최소 읽기 폭을 보장하고 표 영역 안에서 가로 이동할 수 있도록 처리했습니다.

**결과**  
모바일에서도 셀 내용의 문장 가독성을 유지하면서 원래의 비교 표 구조를 그대로 확인할 수 있습니다.

## 로그인 이후 작업 연속성

**문제**  
분석 준비 도중 로그인이 필요한 경우, 사용자가 선택한 흐름이 끊기면 파일과 설정을 다시 준비해야 하는 불편이 발생합니다.

**판단**  
로그인 자체보다 로그인 이후 기존 작업으로 복귀하는 경험을 중요한 설계 기준으로 두었습니다.

**결과**  
온보딩과 작업 화면의 로그인 진입점을 점검하며 분석 시작까지의 이탈 요인을 줄이는 방향으로 개선하고 있습니다.

## 고객센터의 불필요한 인증 요청

**문제**  
공개로 볼 수 있어야 하는 FAQ 화면에서 초기 로딩 시 인증 오류 요청이 발생하면, 사용자가 기능을 누르지 않아도 오류를 경험하게 됩니다.

**판단**  
실제 제공되는 정적 FAQ 데이터와 맞지 않는 네트워크 호출을 제거하여 화면의 책임을 단순화했습니다.

**결과**  
고객센터 진입 시 불필요한 인증 오류 없이 안내 내용을 확인할 수 있도록 정리했습니다.
