# 원페이지 (OnePage)

강의 자료를 올리고, 복습과 시험 대비에 맞는 형태로 정리해 공부를 바로 이어갈 수 있도록 돕는 AI 학습 서비스입니다.

[서비스 바로가기](https://1-page.site/)

## 왜 만들었는가

대학생이 시험 기간에 마주하는 문제는 자료가 없어서가 아니라, 많은 자료를 다시 읽고 정리하는 데 시간이 오래 걸린다는 점입니다. 원페이지는 자료 정리에 소모되는 시간을 줄이고, 사용자가 이해와 복습에 집중할 수 있도록 만드는 데 목적이 있습니다.

## 무엇을 제공하는가

| 영역 | 제공 기능 |
| --- | --- |
| 입력 | PDF, PPTX, DOCX 강의 자료 업로드 |
| 준비 | 학습 모드와 분석할 페이지 범위 선택 |
| 결과 | 강의 복습용 정리, 핵심 요약, 문제 생성 |
| 학습 | 원본과 결과를 오가며 확인하고 결과를 다시 열람 |
| 관리 | 개인 라이브러리에서 생성 자료 관리 |

## 기본 사용 흐름

```text
Google 로그인
  -> 자료 업로드
  -> 학습 모드 및 분석 범위 선택
  -> AI 분석 진행
  -> 결과 확인
  -> 라이브러리에서 다시 학습
```

## 구현 구성

원페이지는 화면 경험을 담당하는 웹 애플리케이션, 사용자 및 이용 상태를 관리하는 서비스 API, 자료 분석을 수행하는 AI 작업 서비스로 구성됩니다. 서비스는 Google Cloud 환경에서 운영되며, 분석 결과를 사용자 흐름에 맞춰 다시 확인할 수 있도록 연결합니다.

> 이 Wiki는 서비스 구조와 의사결정을 공개 가능한 수준에서 설명합니다. 비공개 소스 코드, 운영 정보, 사용자 데이터, AI 처리 규칙의 상세 내용은 공개하지 않습니다.
