# 모릭(Mori-Q)

업로드한 강의 자료 중 필요한 페이지 범위만 골라 복습·요약·예열·퀴즈로 다시 활용하고, 결과를 라이브러리에 저장해 시험 때까지 반복해서 이어서 공부할 수 있도록 돕는 AI 학습 워크스페이스입니다.

[서비스 바로가기](https://1-page.site/)

## 왜 만들었는가

서비스 초기에는 자료 전체를 업로드하면 AI가 한 번에 요약해주는 형태로 시작했습니다. 하지만 실제 사용 데이터를 확인해보니, 학생들은 자료 전체를 한꺼번에 정리하기보다 시험 범위나 다음 수업 진도처럼 필요한 페이지 범위만 골라 반복적으로 공부하는 경우가 훨씬 많았습니다(분석 요청의 90% 이상이 특정 페이지 범위 선택 기준). 이 사용 패턴을 바탕으로 모릭(Mori-Q)는 "AI가 요약을 대신 해준다"는 기능 하나가 아니라, 필요한 자료를 필요한 시점에 다시 찾아 학습을 이어갈 수 있는 흐름을 제공하는 방향으로 발전했습니다.

## 무엇을 제공하는가

| 영역 | 제공 기능 |
| --- | --- |
| 입력 | PDF, PPTX, DOCX 강의 자료 업로드 |
| 준비 | 학습 모드와 분석할 페이지 범위 선택 |
| 결과 | 강의 복습, 핵심 요약(벼락치기), 예열, 문제 생성 |
| 학습 | 원본과 결과를 오가며 확인하고 결과를 다시 열람 |
| 관리 | 개인 라이브러리(학습 세트)에서 생성 자료를 다시 찾아 이어서 학습 |

## 기본 사용 흐름

```text
Google 로그인
  -> 자료 업로드
  -> 학습 모드 및 분석 범위 선택
  -> AI 분석 진행
  -> 결과 확인
  -> 라이브러리에서 다시 학습
```

## 구현 구성

모릭(Mori-Q)는 화면 경험을 담당하는 웹 애플리케이션, 사용자 및 이용 상태를 관리하는 서비스 API, 자료 분석을 수행하는 AI 작업 서비스로 구성됩니다. 서비스는 Google Cloud 환경에서 운영되며, 분석 결과를 사용자 흐름에 맞춰 다시 확인할 수 있도록 연결합니다.

> 이 Wiki는 서비스 구조와 의사결정을 공개 가능한 수준에서 설명합니다. 비공개 소스 코드, 운영 정보, 사용자 데이터, AI 처리 규칙의 상세 내용은 공개하지 않습니다.
