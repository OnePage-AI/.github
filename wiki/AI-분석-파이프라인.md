# AI 분석 파이프라인

## 목적

원페이지의 AI 기능은 긴 자료를 단순히 한 문단으로 줄이는 것이 아니라, 사용자가 선택한 학습 목적에 맞춰 다시 공부하기 쉬운 결과를 제공하는 데 목적이 있습니다.

## 공개 가능한 처리 흐름

```text
자료 업로드
  -> 분석 가능한 형태로 준비 (이미지 및 텍스트 추출)
  -> RAG 인덱싱 및 지식 구조화
  -> 학습 모드별 계층적 분석 파이프라인 가동 (v5.0)
     1. Semantic Anchor (문서 뼈대 구축)
     2. Sequential Batch Processing (순차적 배치 처리)
     3. Final Synthesis (결과 합성)
  -> 비동기 분석 작업 완료 및 결과 저장
```

분석 결과는 학습 모드에 따라 복습용 정리, 핵심 요약, 문제 생성 형태로 제공됩니다. 특히 v5.0에서는 수백 페이지에 달하는 대용량 문맥을 안정적으로 처리하기 위해 **순차적 배치 처리(Sequential Batch Processing)** 기술을 도입하여, 모델의 한계를 극복하고 일관된 요약 품질을 유지합니다.


분석 결과는 학습 모드에 따라 복습용 정리, 핵심 요약, 문제 생성 형태로 제공됩니다. 원본과 결과를 함께 확인할 수 있도록 페이지 단위의 참고 흐름도 사용자 경험에 반영합니다.

## 비동기 처리 이유

자료 분석은 파일 분량과 선택 범위에 따라 시간이 필요합니다. 작업을 별도 처리 흐름으로 분리하여 다음을 가능하게 합니다.

- 사용자가 분석 요청 이후 진행 상태를 확인할 수 있습니다.
- 결과 생성 중 화면의 주요 상호작용이 불필요하게 막히지 않습니다.
- 결과를 라이브러리에 연결해 이후 다시 열람할 수 있습니다.
