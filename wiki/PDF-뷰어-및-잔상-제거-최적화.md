# [트러블슈팅] PDF 뷰어 렌더링 최적화: iframe 리프레시 및 잔상(Ghost Data) 현상 해결

## 1. 문제 상황
사용자가 분석 모드(복습, 요약 등)를 전환하거나 고급 설정을 변경할 때마다, 우측의 **PDF 뷰어가 초기화되어 첫 페이지로 돌아가거나 깜빡이는 현상**이 발생했습니다. 또한, 새로운 분석을 시작했음에도 이전 모드의 결과 데이터가 화면에 잠시 남아있는 **잔상(Ghost Data) 현상**이 사용자에게 혼란을 주었습니다.

## 2. 병목 분석 및 가설
*   **iframe 리프레시**: React의 상태 변경이 부모 컴포넌트를 리렌더링하면서, `iframe` 요소의 `key`가 명시되지 않거나 URL에 불필요한 파라미터가 포함되어 브라우저가 이를 새로운 요소로 인지하고 다시 로드하는 것이 원인이었습니다.
*   **잔상 현상**: 비동기 작업이 시작될 때 이전 결과 상태(`result`)를 즉시 초기화하지 않고, 새 결과가 도착할 때까지 기존 데이터를 유지하는 로직 때문이었습니다.

## 3. 해결 시도 및 구조 재설계

### 3.1. iframe key 최적화
PDF 뷰어 컴포넌트에 고정된 고유 키를 부여하고, URL 변경 시에도 `iframe` 객체 자체는 유지되도록 메모이제이션(memo)을 적용했습니다. 이를 통해 설정 변경 시에도 PDF의 현재 스크롤 위치가 보존됩니다.

### 3.2. 상태 초기화 및 로딩 동기화
새로운 분석 요청이 발생하는 즉시 `setResult(null)`을 호출하여 이전 데이터를 명시적으로 비우는 **Clean-up 로직**을 강화했습니다.
```typescript
const handleStartAnalysis = async () => {
  setResult(null); // Ghost Data 제거
  setIsAnalyzing(true);
  // ... 분석 요청 로직
};
```

## 4. 최종 안정화 및 결과
*   **끊김 없는 UX**: 모드 전환이나 설정 변경 시에도 PDF 문서는 흔들림 없이 유지되어 학습 흐름을 방해하지 않습니다.
*   **정확한 피드백**: 분석 시작 시 즉시 화면이 비워지고 로딩 애니메이션이 노출되어, 시스템이 새로운 작업을 수행 중임을 사용자에게 명확히 전달합니다.

화려한 기능보다 **'보여주는 방식의 세밀함'**이 학습 서비스의 전문성을 결정짓는 핵심 요소임을 체득했습니다.
