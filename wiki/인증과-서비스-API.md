# 인증과 서비스 API

## 인증 흐름

원페이지는 Google 로그인을 통해 사용자를 인증합니다. 웹 애플리케이션에서 로그인 경험을 제공하고, 서비스 API와 분석 요청은 인증된 사용자 흐름을 기준으로 처리됩니다.

## 서비스 API 역할

Spring Boot 기반 서비스 API는 사용자와 관련된 서비스 상태를 담당합니다.

- 로그인 사용자 연계
- 이용 가능 횟수와 크레딧 정보 제공
- 공지 및 문의와 같은 서비스 운영 기능 처리

분석 결과와 라이브러리 화면에서는 로그인한 사용자가 자신의 작업을 이어서 확인하는 흐름을 중심으로 구성합니다.

## 책임 분리

| 영역 | 담당 |
| --- | --- |
| 화면 및 로그인 인터랙션 | Web Application |
| 사용자 및 서비스 상태 | Service API |
| 파일 분석 및 결과 생성 작업 | Analysis Service |

프론트엔드가 데이터베이스에 직접 접근하지 않고 API를 통해 필요한 상태를 조회하도록 역할을 분리합니다.

## 보안 관련 공개 범위

이 문서는 인증 방식과 책임 분리까지만 설명합니다. 토큰 처리 세부, 내부 서비스 인증 방식, 운영자 접근 정책, 데이터 식별 규칙은 공개 문서에 포함하지 않습니다.
