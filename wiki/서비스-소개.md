# 서비스 소개

## 문제

강의 자료는 슬라이드, 배포 문서, 복습 자료로 쌓이지만 시험 전에는 모든 내용을 처음부터 다시 정리하기 어렵습니다. 특히 시험 범위나 다음 수업 진도처럼 자료의 일부만 반복해서 봐야 하는 경우, 매번 자료 전체에서 필요한 부분을 다시 찾아야 하는 번거로움이 있습니다.

## 모릭(Mori-Q)의 접근

서비스 초기에는 자료 전체를 업로드하면 한 번에 요약해주는 형태로 시작했습니다. 하지만 실제 분석 요청의 90% 이상이 자료 전체가 아닌 특정 페이지 범위를 선택해 이뤄진다는 사용 데이터를 확인한 뒤, 모릭(Mori-Q)는 자료 전체가 아니라 필요한 범위만 선택해 반복적으로 학습하는 방향으로 발전했습니다.

사용자는 올린 강의 자료 중 필요한 범위와 학습 목적에 맞는 결과를 선택합니다.

- 전체 내용을 다시 따라가고 싶을 때는 `강의 복습` 형태로 확인합니다.
- 시험 전 빠르게 구조를 잡고 싶을 때는 `핵심 요약` 형태로 확인합니다.
- 낯선 범위의 맥락을 먼저 잡고 싶을 때는 `예열`을 이용합니다.
- 스스로 점검하고 싶을 때는 `문제 생성`을 이용합니다.

정리 결과는 단발성 출력으로 끝나지 않고 라이브러리(학습 세트)에 저장되어, 시험 때까지 다시 열어 이어서 공부할 수 있습니다.

## 대상 사용자

- 강의 자료를 다시 정리하는 시간보다 복습 시간에 집중하고 싶은 대학생
- 시험 전 여러 주차 자료를 빠르게 훑어야 하는 사용자
- 원본 자료와 정리 결과를 함께 확인하면서 학습하려는 사용자

## 운영 방향

모릭(Mori-Q)는 1인 개발 및 운영 서비스입니다. 기능을 크게 늘리는 것보다 실제 사용 중 불편한 흐름을 찾아 모바일 사용성, 분석 진행 경험, 결과 가독성처럼 학습과 직접 연결되는 부분을 지속적으로 다듬고 있습니다.

## 공개 문서 범위

이 문서에서는 사용자에게 제공되는 흐름과 시스템 역할을 설명합니다. 비공개 저장소 코드, 내부 운영 설정, 상세 AI 처리 규칙은 공개 범위에 포함하지 않습니다.
