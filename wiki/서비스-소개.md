# 서비스 소개

## 문제

강의 자료는 슬라이드, 배포 문서, 복습 자료로 쌓이지만 시험 전에는 모든 내용을 처음부터 다시 정리하기 어렵습니다. 단순히 짧게 줄인 결과만으로는 개념의 연결이나 공부할 우선순위를 파악하기도 어렵습니다.

## 원페이지의 접근

원페이지는 사용자가 올린 강의 자료를 바탕으로, 필요한 범위와 학습 목적에 맞는 결과를 제공합니다.

- 전체 내용을 다시 따라가고 싶을 때는 `강의 복습` 형태로 확인합니다.
- 시험 전 빠르게 구조를 잡고 싶을 때는 `핵심 요약` 형태로 확인합니다.
- 스스로 점검하고 싶을 때는 `문제 생성`을 이용합니다.

정리 결과는 단발성 출력으로 끝나지 않고 라이브러리에서 다시 열어 공부를 이어갈 수 있습니다.

## 대상 사용자

- 강의 자료를 다시 정리하는 시간보다 복습 시간에 집중하고 싶은 대학생
- 시험 전 여러 주차 자료를 빠르게 훑어야 하는 사용자
- 원본 자료와 정리 결과를 함께 확인하면서 학습하려는 사용자

## 운영 방향

원페이지는 1인 개발 및 운영 서비스입니다. 기능을 크게 늘리는 것보다 실제 사용 중 불편한 흐름을 찾아 모바일 사용성, 분석 진행 경험, 결과 가독성처럼 학습과 직접 연결되는 부분을 지속적으로 다듬고 있습니다.

## 공개 문서 범위

이 문서에서는 사용자에게 제공되는 흐름과 시스템 역할을 설명합니다. 비공개 저장소 코드, 내부 운영 설정, 상세 AI 처리 규칙은 공개 범위에 포함하지 않습니다.
