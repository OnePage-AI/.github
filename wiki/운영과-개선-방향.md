# 운영과 개선 방향

## 운영 방식

모릭(Mori-Q)는 직접 개발하고 운영하는 서비스입니다. 사용자 문의와 실제 이용 흐름에서 확인되는 문제를 바탕으로 기능 안정성과 화면 사용성을 함께 점검합니다.

## 현재 중요하게 보는 항목

- 강의 자료를 업로드하고 결과까지 도달하는 흐름이 끊기지 않는지 확인합니다.
- 모바일에서도 결과를 읽고 다시 공부하는 과정이 부담스럽지 않도록 조정합니다.
- 오류가 발생했을 때 원인을 빠르게 좁힐 수 있도록 배포 및 실행 상태를 확인합니다.
- 고객센터와 안내 문구가 실제 제공 기능과 일치하도록 유지합니다.
- Cloud Run 최소 인스턴스와 CPU 할당 설정이 사용자 경험과 운영 비용에 미치는 영향을 함께 점검합니다.

## 기술 문서 운영 원칙

- 구현된 기능만 현재 기능으로 소개합니다.
- 변경 예정 사항은 확정된 제공 기능처럼 표현하지 않습니다.
- 민감한 운영 정보와 내부 분석 구현은 외부 문서로 공개하지 않습니다.
- 사용자 자료나 실행 로그에 포함된 내용을 예시로 공개하지 않습니다.

## 다음 개선을 판단하는 기준

새로운 기능의 수보다 사용자가 자료를 준비하고, 결과를 이해하고, 다시 학습하는 과정이 자연스러운지 여부를 우선합니다. 향후 개선 사항도 실제 사용성 검토와 구현 확인 이후 문서에 반영합니다.

## 최근 운영 개선

- AI 분석 서비스의 유휴 시간 고정비를 줄이기 위해 최소 인스턴스를 0으로 조정했습니다.
- 분석 작업 실행 중 백그라운드 워커가 CPU를 사용할 수 있도록 CPU 할당 방식은 유지했습니다.
- 장기적으로 API 서버와 작업 워커 분리를 검토합니다.
