## 서비스 소개

강의 자료는 많고, 정리할 시간은 제한적입니다. 모릭(Mori-Q)는 PDF, PPTX, DOCX 자료를 업로드하면 사용자가 선택한 학습 방식에 맞춰 내용을 정리하고, 이후 다시 확인할 수 있도록 라이브러리에서 관리합니다.

직접 개발하고 운영하면서 실제 학습 흐름에서 불편한 지점을 빠르게 확인하고 개선하는 것을 목표로 하고 있습니다.

## 제공 기능

| 기능 | 설명 |
| --- | --- |
| 강의 자료 업로드 | PDF, PPTX, DOCX 파일을 업로드해 분석을 시작합니다. |
| 학습 모드 선택 | 복습, 핵심 요약, 문제 생성 목적에 맞춰 결과를 만듭니다. |
| 분석 범위 선택 | 필요한 페이지를 선택해 학습 범위를 조절합니다. |
| 결과 확인 | 정리 결과와 원본 자료를 함께 확인하며 공부를 이어갑니다. |
| 라이브러리 | 생성된 자료를 다시 열어보고 관리합니다. |

## 설계 방향

- 작은 화면에서도 업로드, 설정, 결과 확인의 주요 행동을 쉽게 찾을 수 있도록 모바일 흐름을 정리합니다.
- 분석은 사용자 요청 이후 비동기 작업으로 처리하고 진행 상태를 화면에 전달합니다.
- 웹 애플리케이션, 서비스 API, AI 분석 작업을 분리해 각 역할을 명확히 유지합니다.
