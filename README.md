# OnePage Public Documentation

이 저장소는 원페이지(OnePage)의 공개 소개와 Wiki 기술 문서를 관리합니다.

- 조직 프로필: [`profile/README.md`](profile/README.md)
- Wiki 원본: [`wiki/`](wiki/)
- 서비스: [1-page.site](https://1-page.site/)

## 공개 범위

공개 문서는 서비스가 해결하려는 문제, 사용자 흐름, 구성 요소의 역할, 운영 과정에서의 기술적 판단을 설명합니다.

다음 정보는 이 저장소에 포함하지 않습니다.

- 비공개 서비스 저장소의 소스 코드 및 링크
- API 키, 계정 정보, 데이터베이스 접속 정보, 내부 서비스 주소
- 사용자 업로드 자료 또는 운영 로그 원문
- AI 프롬프트 전문, 분석 단계별 조건, 재현 가능한 내부 처리 규칙

## Wiki 작성 원칙

`wiki`의 Markdown 파일은 검토 후 GitHub Wiki에 게시하기 위한 원본입니다. 실제 동작과 일치하는 범위에서만 기술하며, 변경 예정 사항은 구현 완료 전까지 현재 기능처럼 표현하지 않습니다.
